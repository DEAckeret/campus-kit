Website templates for small colleges that a small team can keep up.

Campus Kit is a hand-written HTML and CSS design system with ready-made pages for programs, events, news and staff directories. It's accessible, prints cleanly, and needs no build tools.

What's in the kit

Each page is shown on College of the Sleeping Giant, a made-up school, so you can see the templates with realistic content.

  • Home page

    A program search in the hero, three paths for new students, key facts, upcoming events and a featured story.

  • Program finder

    Every major, minor and certificate, filterable by school and type. Linking to programs.html?q=nursing opens a filtered list.

  • Program page

    The template a department fills in: overview, outcomes, a course table, careers, and a sidebar with the advisor contact.

  • How to apply

    An Admission page: four steps as a numbered sequence, a deadlines table, a cost snapshot and one call to action.

  • Events and athletics

    A filterable calendar list. Game days get a gold date block.

  • Team page

    A season schedule with results spelled out, a roster table, and the gold athletics accents.

  • Giving page

    An Advancement page: an accessible campaign progress bar, giving levels tied to what each gift pays for, and a donor story.

  • Staff directory

    Search people by name, title or department.

  • News story

    An article layout with an accessible chart and a pull quote.

  • Page not found

    What visitors see at a broken or mistyped address: a program search, popular pages, and the address they tried, ready to send to the web team. Try a broken link.

  • Print flyer

    A letter-size event flyer made from the same colors and type, so print and web stay on brand together.

  • Blank program template

    A commented starting file for adding a new program page.

Made for the people who run the site

Easy to hand off

A step-by-step guide walks faculty and staff through adding a page, written for people who don't code.

Accessible by default

Built to WCAG 2.2 AA: a skip link, visible keyboard focus, labeled forms, and text colors that pass AA contrast with room to spare (body text is 15.6 to 1). Every change is checked automatically, and the performance report shows the latest Lighthouse scores for speed, accessibility and search.

Measures what matters

An analytics guide covers the three numbers that show whether a college site is working, and how to count them without tracking people. The demo marks its key buttons but sends nothing.

One file to rebrand

Colors, fonts and spacing live in tokens.css. Change them once and every page, including the print flyer, follows.

Built entirely by AI

This project is an experiment by Dustin Ackeret. Every line of code, every page, and every word of copy was written by Claude, an AI model, working from Dustin's direction. Dustin chose the goal, reviewed the results, and decided what to build next.

Claude returns on a schedule to build the next item on the roadmap, and each session records what it built, what it got wrong and what it decided in the build log.
