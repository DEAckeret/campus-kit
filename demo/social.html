Social media graphics: Fall choir concert

A square post for Instagram and Facebook feeds and a tall story, both for one event. Each one is saved as a PNG file, ready to upload.

Alt text to post with them

People who use screen readers hear this instead of seeing the graphic. Paste it into the alt text field when you upload either image.

Fall choir concert, part of Music at the Giant. Saturday, November 1, at 7:30 p.m. in St. Brigid Chapel. Free tickets at the door. College of the Sleeping Giant, sleepinggiant.example/events.

Before you post

  • Write the date, time and place in the post itself, too. Many people scroll past the image, and search can't read it.
  • Add the alt text above. It should say everything the graphic says.
  • Use one graphic per event. A graphic that lists several events is hard to read on a phone.
  • Keep the title short: three lines on the square post at most. The export stops if the text doesn't fit.

Make graphics for another event

Someone on the web team makes them from a copy of this page.

  1. Copy demo/social.html and name the copy after the event, for example social-open-house.html.
  2. Change the text in both graphics: the series, the title, and When, Where and Cost. Then change the alt text and the two file names (data-file).
  3. Run npm run social -- demo/social-open-house.html. It saves a square and a story PNG in demo/social/.
  4. Open both PNG files and check them before you post.

The PNG files above are made each time the site is published, in the same web fonts as the site.
